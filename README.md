Algorithm: College Event – Participant Registration

1. Start.

2. Enter Participant Details:
   - Enter Participant ID.
   - Enter Participant Name.
   - Enter Contact Details.

3. Enter Event Details:
   - Enter Event ID.
   - Enter Event Name.

4. Enter Registration Details.

5. Enter Event Date.

6. Check Registration Status.

7. If registration is successful:
   - Display "Registration Successful."

8. Otherwise:
   - Display "Registration Failed."

9. Display Participant Details, Event Details, Registration Details, Event Date, and Registration Status.

10. End.
